A personal collection of AI agents - from small free-tier API agents to production-grade builds.

Part of my Ship It: AI Builds series, where I build and document one functional agent at a time - real code, kept simple, no hype.

If you find this useful, consider leaving a ⭐ - it helps others find it.

Structure

Each agent lives in its own folder under everyday-ai-agents/, with its own app.py, requirements.txt, and README.md - fully self-contained so any single folder can be copied out and run on its own.

ai-foundry/
└── everyday-ai-agents/
    └── quick-10-min-recipe-agent/
        ├── app.py
        ├── requirements.txt
        └── README.md
